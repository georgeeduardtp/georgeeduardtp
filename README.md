## 🚀 Featured project — Pelu Go

<div align="center">

### SaaS B2B2C for hair salon management and online bookings

<a href="https://pelugo.es">
  <img src="https://img.shields.io/badge/Visit%20Pelu%20Go-6D28D9?style=for-the-badge&logo=googlechrome&logoColor=white" alt="Pelu Go"/>
</a>

</div>

**Pelu Go** is a multi-tenant SaaS platform for managing businesses, employees, services, schedules, availability and online bookings, with a private management dashboard and a public storefront for customers.

### What I built

- Backend with **Java, Spring Boot, Spring Security, JPA/Hibernate and PostgreSQL**
- **Multi-tenant architecture** with tenant-aware data isolation and authorization
- **Hexagonal Architecture**, separating domain, use cases, ports, adapters and infrastructure
- Authentication with **JWT, refresh tokens and logout flows**
- **RBAC** for role- and permission-based access control
- Business logic for **businesses, employees, services, schedules, breaks, availability and bookings**
- Frontend integration with **Next.js, React, TypeScript and MUI**
- External services including **Cloudflare R2/S3, Cloudflare Turnstile, MapTiler, Vercel and Railway**
- Endpoint and flow validation with **Postman**
- Application containerization with **Docker**
